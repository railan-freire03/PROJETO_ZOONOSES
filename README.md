
# Projeto de Zoonoses

## Sobre o projeto

Projeto acadêmico desenvolvido no curso de Sistemas de Informação, com o objetivo de construir um banco de dados para o gerenciamento de informações relacionadas à saúde e ao bem-estar animal.

O projeto utiliza dados sintéticos para simular situações encontradas em sistemas de controle de zoonoses.

## Objetivos

- Construir um banco de dados relacional utilizando SQLite.
- Gerar dados sintéticos de animais e registros relacionados.
- Simular inconsistências e problemas de qualidade dos dados.
- Desenvolver processos de tratamento e validação.
- Realizar auditorias para verificar a qualidade das informações.
- Produzir relatórios para análise dos dados.

## Tecnologias utilizadas

- Python
- SQLite
- Google Colab
- GitHub
